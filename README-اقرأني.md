# MMY.YE — بناء ملف ويندوز (EXE) وأندرويد (APK) عبر GitHub

## التحديث على GitHub
1. افتح المستودع ← **Add file ← Upload files**.
2. ارفع كل محتويات هذا المجلد (بما فيها `android-patch` و`assets` و`build` و`www`) واستبدل الملفات القديمة.
3. تأكد أن ملف `.github/workflows/main.yml` (أو build.yml) محدّث بمحتوى `.github/workflows/build.yml` الموجود هنا، لأنه تغيّر.
4. اضغط **Commit changes**، وسيبدأ البناء تلقائيًا من تبويب **Actions**.
5. نزّل الملفين من قسم **Artifacts**.

## ما الجديد
- شعار دائري (قرص أبيض + حلقة داكنة + حلقة خضراء مضيئة) ونجمة خضراء متدرجة في الواجهة، والأيقونة بنفس الشكل.
- أيقونة التطبيق وشاشة البدء بالشعار الرسمي.
- بصمة أصلية في أندرويد (لا تعتمد على WebAuthn).
- ضبط الواجهة داخل حدود شاشة الجوال (شريط الحالة والأزرار).
- تحسين السرعة: الخطوط لا تعطّل البدء، وتعطيل الـ service worker داخل التطبيق.

## ملاحظات
- أول تشغيل: وافق على ظهور نافذة تفعيل البصمة بعد الدخول بكلمة المرور، أو فعّلها من الإعدادات.
- الدخول بالبصمة / Windows Hello في نسخة EXE غير مدعوم، فيُستخدم الدخول بكلمة المرور.
- الـ APK بتوقيع تجريبي (debug) ويصلح للتثبيت المباشر. أما Google Play فيلزمه توقيع release.
- كلمة المرور الافتراضية admin / 1234 — غيّرها فور أول دخول.
